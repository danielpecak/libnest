Citing and Contributing
=======================

Citing
------
If you use libNeST in your research, please cite it using the metadata in
`CITATION.cff <https://github.com/danielpecak/libnest/blob/main/CITATION.cff>`_
(GitHub shows it as "Cite this repository"). Please also cite the papers that
define the functional you use; for BSk31 this is :cite:`chamel2016further`.

Contributing
------------
Bug reports and pull requests are welcome at
`github.com/danielpecak/libnest <https://github.com/danielpecak/libnest>`_.

1. Fork the repository and create a feature branch.
2. Install in editable mode with the test tools: ``pip install -e ".[test]"``.
3. Run the test suite with ``pytest`` and make sure it passes.
4. Open a pull request.
